# Proposal

## Why

ロケハンでは「どの焦点距離のレンズを持っていけばよいか」を事前に知りたい。現在の一人称モードでは撮影地点から見える景色は確認できるが、特定のレンズで写る範囲がわからない（Issue #4）。一人称ビューにレンズの画角枠を重ねて表示し、複数の焦点距離を同時に比べられるようにする。

## What Changes

- 一人称モードで、選んだ焦点距離の画角枠を、視線の中心を中心とする長方形として画面に重ねて表示する。
- 焦点距離は、定番の9種類（24 / 28 / 35 / 40 / 50 / 75 / 85 / 100 / 200mm）から、それぞれ表示・非表示を切り替えて選ぶ。複数を同時に表示でき、枠ごとに焦点距離のラベルと色で区別する。
- センサーはフルサイズ（36 x 24mm、横位置）に固定する。焦点距離は35mm換算の値として扱い、フルサイズ以外のカメラを使う場合は、ユーザーが換算した焦点距離に読み替える。
- 一人称モードの画面の視野を、表示中の最も広い画角枠が画面に収まるように広げる。既定の視野より狭くはしない。

Issue #4 との差分: Issue の完了条件「センサーサイズと焦点距離を選択・入力できる」のうち、センサーサイズの選択と焦点距離の自由入力は本変更では扱わない（フルサイズ固定・定番の焦点距離のみ）。

対象外: センサーサイズの選択、焦点距離の自由入力、縦位置の枠、一人称モードのズーム操作、魚眼レンズ、設定の保存。

## Capabilities

### New Capabilities

- `lens-framing`: 一人称モードでの、35mm換算の焦点距離によるレンズの画角枠の選択と表示、および画角枠を収めるための画面の視野の調整

### Modified Capabilities

なし。`shooting-viewpoint` の一人称モードの要件（視点の位置を固定し、視線の向きだけを変える）は変わらない。画面の視野の調整は視点の位置も視線の向きも変えないため、`lens-framing` 側の要件として定める。

## Impact

- `frontend/src`: 画角の計算（`domain/`）、アプリの状態への表示中の焦点距離の追加（`state/`）、一人称モードの視野の調整（`map/firstPerson.ts`）、画角枠の重ね表示と焦点距離の選択パネル（`ui/`）。
- `CONTEXT.md`: 焦点距離・画角・画角枠などの用語を追加する。
- 依存の追加・外部サービスの変更はない。
