# Spec Delta

## Purpose

一人称モードで、レンズの焦点距離ごとに写る範囲を画角枠として重ねて表示し、ロケハンに持っていくレンズを撮影地点からの景色と比べて選べるようにする。

## ADDED Requirements

### Requirement: 定番の焦点距離から画角枠を選ぶ

システムは、24 / 28 / 35 / 40 / 50 / 75 / 85 / 100 / 200mm の9種類の焦点距離それぞれについて、画角枠を表示するかどうかを切り替えられなければならない（SHALL）。複数の焦点距離を同時に表示する状態にできなければならない（MUST）。アプリを開いた直後は、どの焦点距離の画角枠も表示しない状態でなければならない（MUST）。

#### Scenario: 画角枠を表示する焦点距離を選ぶ

- **WHEN** ユーザーが 50mm の画角枠の表示を選ぶ
- **THEN** 50mm は画角枠を表示する状態になる

#### Scenario: 複数の焦点距離を選ぶ

- **WHEN** 24mm を表示する状態で、ユーザーが 85mm の画角枠の表示も選ぶ
- **THEN** 24mm と 85mm の両方が画角枠を表示する状態になる

#### Scenario: 選択を外す

- **WHEN** 50mm を表示する状態で、ユーザーが 50mm の表示を外す
- **THEN** 50mm は画角枠を表示しない状態になる

#### Scenario: アプリを開いた直後

- **WHEN** ユーザーがアプリを開く
- **THEN** どの焦点距離も画角枠を表示しない状態である

### Requirement: 画角は35mm判フルサイズの横位置で求める

システムは、焦点距離を35mm換算の値として扱い、画角を 36mm x 24mm のフルサイズのセンサーを横位置に置いたときの値として求めなければならない（SHALL）。水平の画角は 2 x atan(18 / 焦点距離)、垂直の画角は 2 x atan(12 / 焦点距離) でなければならない（MUST）。

#### Scenario: 50mm の画角

- **WHEN** 50mm の画角枠を表示する
- **THEN** 画角枠は、水平の画角 約39.6°、垂直の画角 約27.0° の範囲を表す

#### Scenario: 24mm の画角

- **WHEN** 24mm の画角枠を表示する
- **THEN** 画角枠は、水平の画角 約73.7°、垂直の画角 約53.1° の範囲を表す

### Requirement: 一人称モードで画角枠を表示する

システムは、一人称モードで、表示する状態の焦点距離それぞれについて、視線の中心を中心とし、その焦点距離の画角で写る範囲と一致する長方形の画角枠を、景色に重ねて表示しなければならない（SHALL）。視線の向きを変えても、画角枠は画面の中央に表示し続けなければならない（MUST）。俯瞰モードでは画角枠を表示してはならない（MUST NOT）。

#### Scenario: 画角枠が表示される

- **WHEN** 50mm を表示する状態で、一人称モードに切り替える
- **THEN** 画面の中央に、50mm の画角で写る範囲を囲む長方形の枠が表示される

#### Scenario: 見回しても画角枠は中央にある

- **WHEN** 一人称モードで画角枠が表示された状態で、ユーザーが視線の向きを変える
- **THEN** 画角枠は画面の中央に表示されたまま、枠の中の景色が視線の向きに合わせて変わる

#### Scenario: 俯瞰モード

- **WHEN** 焦点距離を表示する状態で、ユーザーが俯瞰モードに戻る
- **THEN** 画角枠は表示されない

### Requirement: 画角枠の焦点距離を判別できる

システムは、複数の画角枠を表示しているとき、それぞれの画角枠がどの焦点距離のものかを、画面上の表示で判別できるようにしなければならない（SHALL）。

#### Scenario: 複数の画角枠の判別

- **WHEN** 一人称モードで 35mm と 100mm の画角枠を同時に表示する
- **THEN** それぞれの画角枠に、その焦点距離（35mm、100mm）を示すラベルが表示される

### Requirement: 画角枠が画面に収まるように視野を広げる

システムは、一人称モードで、表示中の画角枠のいずれかが既定の視野（画面の長い辺の方向に 60°）の画面に収まらない場合、すべての画角枠が画面の縦横に収まるまで画面の視野を広げなければならない（SHALL）。画面の視野を既定より狭くしてはならない（MUST NOT）。視野を変えても、視点の位置と視線の向きは変えてはならない（MUST NOT）。

#### Scenario: 広角の画角枠が画面に収まる

- **WHEN** 横長の画面の一人称モードで、24mm の画角枠を表示する
- **THEN** 画面の視野が広がり、24mm の画角枠の全体が画面の中に表示される
- **AND** 視点の位置と視線の向きは変わらない

#### Scenario: 望遠の画角枠だけを表示する

- **WHEN** 一人称モードで、100mm と 200mm の画角枠だけを表示する
- **THEN** 画面の視野は既定のまま変わらない

#### Scenario: 画角枠を表示しない

- **WHEN** 一人称モードで、どの画角枠も表示しない
- **THEN** 画面の視野は既定のまま変わらない

#### Scenario: 画面の縦横比が変わる

- **WHEN** 一人称モードで画角枠を表示した状態で、画面の幅や高さが変わる（スマホの向きを変えるなど）
- **THEN** 変わった後の画面でも、すべての画角枠の全体が画面の中に表示される

#### Scenario: 俯瞰モードに戻る

- **WHEN** 一人称モードで視野が広がった状態から、ユーザーが俯瞰モードに戻る
- **THEN** 俯瞰モードの視野は既定に戻る
