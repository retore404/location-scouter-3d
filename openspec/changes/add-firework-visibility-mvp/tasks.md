## 4. 撮影地点と一人称モード（shooting-viewpoint）

- [x] 4.1 撮影地点を置く道具を実装する。クリック位置の緯度経度から地表の楕円体高を取得し、地上高 1.5m で表示する。開発サーバーで、撮影地点を置けることと、置き直すと1つに置き換わることを確認する
- [x] 4.2 撮影地点の緯度・経度・地上高を表示・編集するパネルを実装する。不正な値は受け付けず、理由を表示する。開発サーバーで、地上高 350m を入力すると表示上の高さが変わることを確認する
- [x] 4.3 一人称モードを実装する。標準のカメラ操作を無効にし、ドラッグ・スワイプで方位と仰角だけを変える。仰角は -90°〜90° に制限する。開発サーバーで、見回しても視点の位置が変わらないことを確認する
- [x] 4.4 一人称モード開始時の向き（最も近い花火の開花範囲の中心、なければ北・仰角 0°）と、方位・仰角の表示を実装する。開発サーバーで、花火の有無それぞれで開始時の向きが仕様どおりであることを確認する
- [x] 4.5 俯瞰モードへ戻る操作を実装し、撮影地点と花火の配置が保たれるようにする。開発サーバーで、行き来しても配置が変わらないことを確認する
