# Proposal

## Why

「あの展望フロアから、あの花火大会の花火が見えるか」を、現地へ行く前に確かめる手段がない。都市の3Dデータ上で撮影地点に視点を固定し、花火が開く位置と大きさを上空に表示できれば、手前の建物に遮られるかどうかを目で確認できる。本変更は、ロケハンアプリの最初の価値として、この確認を実現する。

## What Changes

- 東京23区と横浜市について、PLATEAU の3D都市モデル（建物）と地形を3D表示する。データは PLATEAU の配信サービスを直接利用し、変換や自前ホスティングは行わない。
- 俯瞰モードで、地図上をクリックして撮影地点を1つ置けるようにする。緯度・経度・地上高を数値で確認・修正できるようにする。
- 俯瞰モードで、地図上をクリックして花火（打上地点と号数）を複数置けるようにする。号数から決まる開花高度に、開花直径の大きさの半透明の球を表示する。
- 撮影地点の位置に視点を固定して見回す一人称モードを追加する。俯瞰モードとの間を行き来できるようにする。
- 3D都市モデルに含まれない遮蔽物（樹木、対象範囲外の建物など）がある旨を画面に表示する。
- フロントエンドのワークスペースパッケージ `frontend` を新規作成する。

対象外（後続の issue で扱う）: レンズの画角枠（#4）、焦点距離の提示（#5）、視錐台の表示（#6）、花火以外の被写体（#7）、太陽・月（#8）、保存・共有（#9）、可視領域解析（#10）、花火らしい描画（#11）、地名検索（#12）、対象地域の拡大（#13）。

## Capabilities

### New Capabilities

- `city-model-display`: 対象地域の3D都市モデル（建物）と地形の表示、俯瞰モードの操作、データに含まれない遮蔽物についての注記
- `shooting-viewpoint`: 撮影地点の配置・編集と、撮影地点に視点を固定した一人称モード
- `firework-subject`: 花火（打上地点と号数）の配置・編集と、開花範囲の表示

### Modified Capabilities

なし（既存の spec はない）。

## Impact

- 新規パッケージ: `frontend`（`pnpm-workspace.yaml` で既に宣言済み。ディレクトリは未作成）。
- 依存の追加: CesiumJS ほかフロントエンドのビルド・UI 関連パッケージ。
- 外部サービスへの依存: PLATEAU 配信サービス（データカタログAPI、建物の 3D Tiles、地形の quantized-mesh）と、国土地理院の地理院タイル。PLATEAU 配信サービスは試験運用・無償で、提供期間やサービスレベルの保証がない。
- ルート設定: `vitest.config.ts` の `test.projects`、knip の対象に `frontend` を加える。
- `tools/*` は本変更では作成しない。
